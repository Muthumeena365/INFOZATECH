# InfozaTech Task 1 — Personal Portfolio Website

A responsive dark-themed personal portfolio built with HTML and CSS (with a small JavaScript snippet for the mobile navigation menu and current year).

## Run locally
1. Extract this folder.
2. Open it in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
- Your email, LinkedIn and GitHub links have been filled in from your supplied resume. Check that they are correct.
- Your resume PDF is included as `resume.pdf`, and the Download CV button links to it. The Download CV button links to that file.
- Check your name and portfolio details.
- Only list skills you can confidently discuss.

## GitHub
Create a public repository named `INFOZATECH`, then upload this project folder. Keep this task in a folder such as `Task-1-Personal-Portfolio/` inside the repository if you will add more internship tasks later.

## Demo video checklist
1. Open the website in a desktop browser.
2. Scroll through Home, About, Skills, Projects and Contact.
3. Resize the browser to show the responsive mobile layout.
4. Test the navigation menu and resume download after adding your real PDF.
5. Explain briefly what you built and which technologies you used.
